## 맥북 앱·게임 1.0

두 개의 macOS 앱(유니버설, macOS 14 이상)을 처음 공개합니다.

**ClipMint** — 메뉴 막대 클립보드 관리자
- ⇧⌘V로 여는 복사 기록 패널, 즉시 검색, 키보드만으로 붙여넣기 (Enter = 서식 없이)
- 스니펫(자리표시자 `{date}` `{date+7}` `{time}` `{clipboard}` `{user}`)
- 텍스트 정리: PDF 줄바꿈·하이픈 복원, 공백 정리, 한 줄 만들기, 대소문자, 중복 줄 제거, JSON 정렬, URL 인코딩
- 복사한 이미지의 글자 인식(OCR, 한·영·일, 기기 내 처리), 링크·색상·파일 인식
- 오프라인·분석 없음, 숨김 복사(비밀번호 관리자) 무시, 무시할 앱 설정, 로그인 시 자동 실행, 한국어/영어

**APPROACH** — 관제 로그라이트 게임
- 트랙패드로 하늘길을 그려 착륙시키기, 교대마다 업그레이드 선택, 아침부터 밤까지 변하는 하늘
- 오늘의 교대(일일 시드) + 결과 복사, 기록 저장
- 그래픽·음악·효과음 전부 코드로 생성, 네트워크 없음

### 설치
`.dmg`를 열고 앱을 응용 프로그램 폴더로 끌어 넣은 뒤 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 한 번 눌러 주세요(서명·공증을 받지 않은 앱이라 뜨는 안내입니다). 자세한 순서는 `mac/README.md`에 있습니다.
