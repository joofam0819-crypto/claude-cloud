# claude-cloud

Claude Code로 만든 앱·게임 모음.

| 프로젝트 | 종류 | 위치 |
|---|---|---|
| **ClipMint** | macOS 메뉴 막대 클립보드 관리자 (Swift/SwiftUI, OCR, 스니펫) | `mac/clipmint/` |
| **APPROACH** | macOS 관제 로그라이트 게임 (네이티브 셸 + Canvas) | `mac/approach/` |
| Terra | 3D 지구본 웹 앱 | `terra/` |
| NEON DRIFT | 네온 레이싱 웹 게임 | `neon-drift/` |

맥 앱 설치 방법과 사용법은 [`mac/README.md`](mac/README.md)를 보세요. 빌드된 앱은 [Releases](https://github.com/joofam0819-crypto/claude-cloud/releases)에서 내려받습니다.
