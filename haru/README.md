# 하루

습관, 가계부, 구독, 디데이를 한 화면에서 관리하는 아이폰용 웹앱입니다.

## 무엇을 하나요

| 탭 | 하는 일 | 참고한 앱 |
| --- | --- | --- |
| 오늘 | 오늘 할 습관, 오늘 쓴 돈과 쓸 수 있는 돈, 7일 안에 나갈 구독료, 고정한 디데이를 한 화면에 | — |
| 습관 | 한 번 눌러 기록, 연속 기록·최고 기록·30일 달성률, 16주 달력, 지난 날짜 수정 | Streaks (Apple Design Award 2016) |
| 가계부 | 숫자 키패드로 빠른 입력, 예산 대비 사용률, 남은 날 기준 하루 예산, 분류별·날짜별 그래프, 엑셀(.xlsx) 저장 | 편한가계부, 꼬박가계부 |
| 구독 | 다음 결제일·D-day, 한 달/1년 환산 합계, 지금까지 낸 돈, 원·달러 따로 합산 | Bobby |
| 디데이 | 남은 날(D-n), 며칠째(시작일=1일, 100일·1주년 목록), 매년 반복(생일·기념일), 주말 뺀 평일 수 | 한국형 디데이 앱 |

설계에 반영한 점 (습관 앱 비교·분석 글 기준, 2차 자료):
- 연속 기록이 0으로 끊길 때 그만두는 사용자가 많다는 지적이 반복돼, 연속 기록 옆에 30일 달성률을 함께 보여 줍니다.
- 기록까지 걸리는 단계가 적을수록 오래 쓴다는 분석에 따라, 습관은 한 번 탭, 지출은 키패드 한 화면으로 끝나게 했습니다.

## 파일

- `app.html` — 앱 본체(HTML·CSS·JS 한 파일). Claude 아티팩트로 그대로 게시할 수 있는 형식입니다.
- `pwa/` — 홈 화면 설치용 독립 실행 버전(오프라인 동작, 아이콘, manifest, service worker). `app.html`에서 생성합니다.
- `tools/build-pwa.js` — `app.html`을 바꾼 뒤 `node haru/tools/build-pwa.js`로 `pwa/`를 다시 만듭니다.
- `tools/make-icons.js`, `tools/icon.svg` — 아이콘을 바꿀 때만 실행합니다(Playwright 필요).

## 데이터 저장

- Claude 아티팩트로 열면: 로그인한 본인 계정 전용 저장소(`data/users/<id>/`)에 저장되어 휴대폰과 PC에서 같은 내용이 보입니다. 다른 사람에게는 보이지 않습니다.
- `pwa/`를 직접 호스팅해 열면: 그 기기 브라우저에만 저장됩니다. 설정의 "백업 파일 저장"으로 가끔 백업해 두세요.
- 처음 열면 예시 데이터가 보이고, "예시 지우기"를 누르면 예시만 지워집니다(직접 넣은 기록은 남음).

## 알려진 한계

- 웹앱이라 결제일·습관 알림(푸시)은 없습니다. 오늘 탭에서 7일 안의 결제를 모아 보여 주는 방식으로 대신합니다.
- 평일 계산에 공휴일은 들어가지 않습니다. 음력 생일은 지원하지 않습니다.
